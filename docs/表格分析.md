## 二、定价引擎（库存表，逐车）

```
车辆成本 AD = 打款价 AA + 入库前费用 AB + 入库后费用 AC
  AB = SUMIF(费用明细表!B:B, 本车后6位, 费用明细表!Q:Q)   # 入库前成本合计
  AC = SUMIF(费用明细表!B:B, 本车后6位, 费用明细表!AG:AG) # 入库后成本合计
利润率 AE = IFS(成本≤10万,12%; ≤15万,10%; ≤20万,9%; ≤25万,8%; ≤30万,7%; ≤35万,6%; >35万,6%)
周期降价 AF = IFS(库存天数BC≤10,0%; ≤20,-1%; …每10天-1%…; ≤140,-13%; >150,-14%)  # 141–150 天无分支（见疑点 2）
利润值 AG = (AE + AF) × AD
水牌价幅度 AH = IFS(成本≤10万,6000; ≤15万,7000; ≤20万,8000; ≤25万,9000; ≤30万,10000; ≤35万,11000; >35万,12000)
批发底价标准 AI = IFS(成本≤5万,4000; ≤10万,5000; ≤15万,6000; ≤20万,7000; ≤25万,8000; >20万,9000)  # 分支重叠（见疑点 3）
销售底价标准 AJ = IFS(成本≤10万,4000; ≤15万,5000; ≤20万,6000; ≤25万,7000; ≤30万,8000; ≤35万,19000; >35万,10000)  # 19000 疑似笔误（见疑点 1）；AJ 无下游引用
当期批发价 AK = AI + AD
销售底价 AL = AD + AG
展厅标价 AM = AL + 5500        # 5500 为固定加价（见待确认 6）
网络标价 AN = AH + AG + AD
合计成交价 AW = SUM(合同销售价 AO : 其他 AV) = 合同价 + 贷款返点 + GPS返点 + 保险返点 + 质保利润 + 其他×3
库存时间 BC = DATEDIF(入库时间 BB, TODAY(), "D")
周转天数 BE = DATEDIF(入库时间 BB, 出售时间 BD, "D")
```

验算（查询表示例行）：成本 168270 → AE 9%、AF −14%、AG −8413.5、AH 8000、AI 7000、AJ 6000、AK 175270、AL 159856.5、AM 165356.5、AN 167856.5，全部吻合。

## 三、提成引擎（业绩表，逐车；以业绩表为准，Sheet1 为旧版）

```
运营费用比例 G = IFS(收车成本F<5万,2%; <10万,1.8%; <15万,1.6%; <20万,1.4%; <25万,1.2%; ≥25万,1%)
  其中 F = 车辆成本（库存表 AD），不是打款价
费用减半系数 H = IF(OR(收购来源="调同行车", 周转天数E>15), 1, 2)   # 15 天内售出且非调车，运营费减半
运营费用 I = (G / H) × F
成本合计 J = I + F
卖价合计 K = SUMIF(库存表!B:B, 本车, 库存表!AW:AW)
利润合计 L = K − J
收车提成比例 N = 边表 IFS(台次≤1,16%; ≤2,18%; ≤3,20%; ≤4,22%; ≤5,24%; ≤6,26%; >6,26%)
  台次 = 本业绩表内该收车人名下车数（Y 列每车计 1）；边表为固定 14 人名单（AE7:AE20 / AI7:AI20），新人 10–15% 阶梯未被任何公式引用（见疑点 4）
车辆亏损金额 O = K − F
亏损担责比例 P = IF(O<0, N, 0)
担责金额 Q = P × O × −1        # 亏损额 × 提成比例
收车提成 S = IF(Q>0, −Q, L × N)  # 亏损时收车提成变负数扣款，不再拿利润提成
卖车提成比例 U = 边表 IFS（与 N 同规则，按卖车人台次）
卖车提成 W = (L − S) × U
公司利润 Z = L − S − W
补贴金额 R = IFS(K−F<0, 0; K−F<4000, L×20%; K−F>4000, 0)          # 计算后未被任何公式使用（见疑点 5）
销售补贴 V = IFS(亏损且F<10万,500; 亏损且F<20万,800; 亏损且F>20万,1000; 盈利,0)  # 同样未被使用（见疑点 5）
```

Sheet1（旧版）差异：运营费固定 2%（15 天内改 1%）；亏损担责固定 20%；提成阶梯按 ≤3 台起（16%）且李俊华有个人阶梯 16–21%；销售补贴为手工数（500/800/1000）；含合车/汇款分成手写备注（见待确认 9）。

## 四、工资引擎（提成工资计算表，按月）

```
基础工资 G = SUMIF(表头内容!B43:B61, 岗位职级, 表头内容!G43:G61)
  底薪：新人 2000 / 正式 1000 / 资深 1300 / 精英 1600 / 正式部门经理 1900 / 资深部门经理 2200 /
  储备店长 2500 / 副店长 2800 / 店长 3100 / 事业部负责人 3400 / 财务 4000 / 正式财务 4500 /
  财务经理 5000 / 摄影 4000 / 摄影剪辑 5000 / 运营 6000 / 运营负责人 7000 / 副总经理 5000 / 总经理 6000
考勤工资 H = G / 应出勤 E × 实际出勤 F      # E 均为 26 天；F 手工录入
收购数量 I = SUMIF(业绩表!M:M, 本人, 业绩表!Y:Y)；收购提成 J = SUMIF(业绩表!M:M, 本人, 业绩表!S:S)
销售数量 K = SUMIF(业绩表!T:T, 本人, 业绩表!Y:Y)；销售提成 L = SUMIF(业绩表!M:M, 本人, 业绩表!W:W)  # 注：L 用 M 列匹配，疑似应为 T 列（见疑点 6）
应发提成 M = L + J
提留金额 N = M × 15%；本月提成 O = M − N
实扣工资合计 X = SUM(迟到/缺卡 P : 社保扣除 W)   # 扣款标准均手工录入，无公式
实发工资 AA = O + 话费补贴 Y + 其他补贴 Z − X
公户发 AB 手工录入；私户发 AC = AA − AB
合计行 34 行汇总 G–AC。
阶梯表 H–M 列（新人 10%/15%、正式 16%/26%、部门经理以上团队 5%、店长利润 5%、财务经理等利润 2%）无任何公式引用（见疑点 4、待确认 7）。
```

## 六、疑点与冲突（需客户拍板，见正文第 7 节问题清单）

1. AJ 销售底价标准 30–35 万档为 19000，破坏单调（8000→19000→10000），疑似应为 9000。
2. AF 周期降价 141–150 天无分支，IFS 会返回 #N/A。
3. AI 批发底价标准分支重叠（≤25 万→8000 与 >20 万→9000），IFS 取首个匹配，20–25 万档实际取 8000。
4. 新人 10–15% 阶梯、团队 5%、利润 5%/2% 均无公式引用；业绩表对所有人硬编码 16–26% 阶梯。
5. 业绩表 R（补贴金额）、V（销售补贴）算出后未进入任何合计/工资公式；AC 列（收购资源包收购补贴）全空。
6. 工资表 L（销售提成）用 `SUMIF(业绩表!M:M, 本人, W:W)` 以收车人列匹配，疑似应为 T 列（卖车人）。
7. 费用明细表 E 列（收购）VLOOKUP 取库存表第 34 列（批发底价标准 AI），疑似应取打款价/车辆成本。
8. 库存表 AJ 与 AL 同名“销售底价”，AJ 无下游引用；以哪个为准？
9. 业绩表 R 在 K−F 恰为 4000 时、V 在亏损且成本恰为 20 万时均无分支，返回 #N/A。
10. 业绩表/工资表无月份字段，月度范围靠“本表内数据”隐含；查询表用出售时间段 FILTER——系统需明确按出售时间自然月统计。
